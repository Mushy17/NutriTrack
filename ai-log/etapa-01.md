## Key requests

### 1. Project theme and data model

- Asked: I requested feedback on my idea for a nutrition and physical activity tracking application and help adapting it to the mandatory project requirements.
- Got: Suggestions for structuring the main entries using the required fields: name, boolean status, fixed tag, category and user.
- Changed or rejected: I decided to keep meals and physical activities in the main list and to treat custom recipes as a separate module.

### 2. HTML structure

- Asked: I requested an example of how the Stage 1 page could be structured according to the laboratory requirements.
- Got: A suggested semantic HTML structure with a header, form, list of three entries and footer.
- Changed or rejected: I adapted the content to the NutriTrack theme and used the sample data selected for my project.

### 3. CSS layout

- Asked: I requested guidance for implementing the required desktop/mobile layout, dark mode and accessibility states.
- Got: Suggestions using CSS Grid, Flexbox, CSS variables, media queries and `:focus-visible`.
- Changed or rejected: I selected the colors and visual direction for NutriTrack and tested the interface at multiple screen sizes.

## What I learned / what did not work

I learned how to organize a page using semantic HTML and how Grid and Flexbox can be used together.
I configured and tested the responsive layout at 400 px and 320 px.
I also tested keyboard focus, hover states and the automatic dark theme.
I used the AI suggestions as implementation guidance and verified the result manually in the browser and DevTools.
